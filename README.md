# ECG Signal Processing Using MATLAB

An academic biomedical signal-processing project completed in **2025**, focused on ECG signal analysis, preprocessing, and QRS complex detection using MATLAB and the Pan–Tompkins algorithm.

## Project Overview

An electrocardiogram (ECG) records the electrical activity of the heart over time. This project explores ECG signal processing techniques to visualize cardiac signals, reduce unwanted noise, and identify important features such as QRS complexes and R-peaks.

## Objectives

- Analyze and visualize ECG signals using MATLAB.
- Understand ECG sampling frequency and signal characteristics.
- Apply signal preprocessing and filtering techniques.
- Explore frequency-domain analysis using the Fast Fourier Transform (FFT).
- Detect QRS complexes and R-peaks using the Pan–Tompkins algorithm.
- Estimate heart rate using RR intervals.

## Dataset

- **Source:** [MIT-BIH Arrhythmia Database — PhysioNet](https://physionet.org/content/mitdb/1.0.0/)
- **Record:** 100
- **Sampling frequency:** 360 Hz
- **Channels:** MLII and V5
